Full license texts are in `licenses/` and embedded into the executable. The “帮助 / 许可” dialog displays them without a network connection. No CAD fonts, commercial converter SDKs, or LibreCAD/QCAD source are bundled.

NuGet dependencies and integrity hashes are pinned in `src/CadView/packages.lock.json`. The net8.0 target of ACadSharp 3.7.16 has no additional NuGet dependencies; shared CSMath/CSUtilities code is included in its assembly.

The two files in `samples/` are generated by our own test code and are covered by this project's MIT license. Upstream ACadSharp samples under ignored `.tools/` are only local test inputs and are not included in the release or project samples.

This inventory describes the current build. Check again when dependencies or runtime versions change. DWG/DXF compatibility descriptions do not imply endorsement by Autodesk or other CAD vendors.

GPU dependency license texts are retained in `licenses/Vortice.Windows.txt`, `Vortice.Mathematics.txt`, `SharpGenTools.txt`, and `LibTessDotNet.txt`. For LibTessDotNet the upstream tagged source license is used, rather than the differing NuGet license label. Direct3D is provided by Windows; no proprietary CAD SDK is added.
